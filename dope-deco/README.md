# Dope Deco

Website for Dope Deco, Christmas styling for retail, hospitality, offices and homes.

A single-page site (`index.html`) built with three.js, GSAP ScrollTrigger and Lenis, loaded from cdnjs. Images and video loops live in `img/`.

Open `index.html` through any static server, for example `python3 -m http.server`, then visit http://localhost:8000.

The booking brief has no backend yet: the live site needs a form service to email briefs with attachments.
